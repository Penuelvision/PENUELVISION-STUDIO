Панель управления портфолио

Загрузите файл videos.js с сервера — панель прочитает ролики, порядок и категории.

Перетащите videos.js сюда или нажмите, чтобы выбрать файл
PENUELVISIONпанель управления

Перетаскивайте строки мышью или впишите номер позиции в поле слева и нажмите Enter. Порядок отдельный для каждой категории.

Категории правятся сразу в трёх файлах: ключи в videos.js, названия в penuel.js, кнопки в portfolio.html. Привяжите файлы на вкладке «Выгрузить» — панель сделает это согласованно. Перетаскивайте строки, чтобы изменить порядок кнопок на сайте.

Добавить категорию

Ключ создаётся автоматически из названия. Русские слова транслитерируются.

HTML-файлы сайта

Привяжите все страницы — панель подставит в них один и тот же номер версии. Без этого браузеры год держат старый CSS и JS из кэша.

Обложки на YouTube

В penuel.js есть номер, который заставляет браузер скачать обложки заново. Привяжите файл и поднимите номер, когда поменяете обложку на YouTube.
