1. ОШИБКИ ВАЛИДАЦИИ НЕ ИСЧЕЗАЛИ
   contact.html + penuel.js

   Было: clearErrors() вызывался только в обработчике submit, поэтому
   четыре заполненных поля продолжали показывать красные сообщения до
   следующего нажатия Send.

   Стало: у каждого поля свой обработчик. На input сообщение снимается
   сразу; на change поле проверяется заново (для select и галочки);
   на blur помеченное поле перепроверяется, если его очистили.

   Проверено: 5 ошибок на пустой форме → 0 после заполнения, классов
   has-error тоже 0.

2. АВТОЗУМ iOS
   penuel.css

   Было 15.2px. iOS Safari увеличивает страницу при фокусе на поле
   с шрифтом меньше 16px и не возвращает масштаб назад.

   Стало: .input, .select, .textarea { font-size: 16px } в брейкпоинте
   ≤640px. Viewport без maximum-scale сохранён — доступность не
   ограничена.

   Проверено: все четыре поля 16px.

6. ШРИФТЫ: 866 КБ И БЕЗ КЭША
   assets/fonts/ + penuel.css + htaccess-добавить.txt

   TTF → WOFF2:

     inter-regular        325 КБ → 108 КБ
     montserrat-bold      181 КБ →  64 КБ
     montserrat-medium    180 КБ →  62 КБ
     montserrat-semibold  181 КБ →  63 КБ
     ──────────────────────────────────────
     итого                866 КБ → 297 КБ   (−66%)

   В @font-face WOFF2 первым, TTF запасным. Preload в восьми HTML
   переведён на .woff2 — иначе браузер всё равно тянул TTF.

   Проверено: запрашиваются только woff2, TTF — 0.

   TTF на сервере оставьте, они запасной вариант и больше не качаются.

   Кэш: у шрифтов не было Cache-Control. Правило в
   htaccess-добавить.txt ставит max-age=31536000, immutable.

7. REDUCED MOTION НЕ ОСТАНАВЛИВАЛ ВИДЕО
   penuel.js

   Стало: при reduced motion видео ставится на паузу, autoplay
   снимается, остаётся постер. Настройка отслеживается на лету — если
   её переключить при открытой странице, видео остановится. При
   возврате на вкладку не возобновляется.

   Проверено в WebKit:
     reduce        → paused: true,  autoplay: false
     no-preference → paused: false, autoplay: true

12. РОЛИКИ ПОПАДАЛИ В КОНЕЦ «ALL» ПОСЛЕ ЗАГРУЗКИ
    penuel.js — главная правка этого выпуска

    Причина: карточки строятся в порядке массива PV_VIDEOS, а порядок
    из панели хранится в PV_ORDER. Функция orderCards() применяла
    PV_ORDER только при клике по фильтру. Поэтому сразу после загрузки
    страницы новый ролик оказывался в конце списка, а стоило нажать
    любую категорию и вернуться в All — всё вставало на места.

    Стало: orderCards(grid, 'all') вызывается сразу после построения
    сетки. Порядок применяется при первой отрисовке, до того как
    посетитель что-то нажал.

    Проверено на реальных данных (81 карточка):
      DOM при первой загрузке == PV_ORDER.all : да
      после F5                                : да
      после перехода AI Video → All           : да

    Второй файл — videos.js — менять НЕ нужно, порядок в нём уже
    правильный. Исправление целиком в penuel.js.
